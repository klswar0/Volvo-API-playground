Volvo API Playground

Build Volvo-connected apps in weeks, not months.

Without heavy or unmaintained libraries.

With your own code.

This project lets you:

  • Build & test apps without owning a car — no physical Volvo required in your garage.
  • Bypass official sandbox limits — reactive simulation instead of rigid mock responses.
  • No OAuth2 setup yet? No worries — you can bypass auth flow and start building right away.
  • Test every edge case possible — simulate low coolant levels, open doors, or no connection in seconds.
  • Snapshots & scenarios system — save custom car states for lightning-fast iteration.
  • Built-in Error logger — capture and analyze HTTP errors without a proxy
  • Dashboard — if you like clicking stuff and seeing live data, we got you covered.

And more!
